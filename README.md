# HANEDIT lite 1.0.1 — 640KB에서 도는 MS-DOS용 VGA 한글 텍스트 편집기

HANEDIT(32비트판, 지금 1.0.2)과 같은 편집기를 **16비트 리얼 모드**로 다시 빌드한 판입니다.
DOS 익스텐더 없이 DOS 기본 메모리(640KB) 안에서 돌아가며, 확장 메모리(XMS/EMS)가 없는
PC에서도 실행됩니다. 화면, 메뉴, 글쇠, 한글 입력, 한자 바꾸기, 자동 줄 바꿈, 설정 파일은
1.0과 같습니다. 버전은 도움말 메뉴의 '이 프로그램은...'에 'HANEDIT lite 1.0.1'로 나옵니다.

## 1.0과 다른 점

| | HANEDIT (32비트판) | HANEDIT lite |
|---|---|---|
| 실행 방식 | 32비트 보호 모드 (DOS/32A) | 16비트 리얼 모드, 익스텐더 없음 |
| CPU | 386 이상 | 16비트 코드 (286 이상 권장, VGA 필요) |
| 필요 메모리 | 3MB 이상 (4MB 권장) | 빈 기본 메모리 약 450KB 이상 권장 |
| 실행 파일 | 약 1.4MB (글꼴 내장) | 약 130KB + 글꼴 파일 `HANEDIT.FNT` 약 1.3MB |
| 글꼴 | 모두 메모리에 | 화면에 나온 글자만 파일에서 읽어 1,024자 캐시(약 36KB)에 둠 |
| 한자 사전 | 한 글자 부분(240KB)을 메모리에 | 색인(4KB)만 메모리에, 후보는 그때그때 파일에서 |
| 문서 크기 | 메모리 한도까지 | 8,000줄, 한 줄 30,000자, 전체 약 15만 자(빈 메모리에 따라 다름) |
| 오려두기 | 제한 없음 | 30,000자까지 |
| 되돌리기 | 1,000번 | 500번, 기록 합계 4만 자. 1만 6천 자가 넘는 편집은 기록하지 않고 기록을 비움 (알림이 나옴) |

한도를 넘는 파일은 불러오지 않고 상태 줄(또는 대화 상자)에 까닭을 알려 줍니다. 이때 지금
문서는 그대로 남습니다. 편집하다 한도를 넘게 되면(줄 수, 줄 길이) 그 편집만 하지 않고 알려 줍니다.
그래도 메모리가 바닥나서 프로그램이 멈춰야 할 때는, 고친 문서를 지금 디렉터리의
`HANEDIT.SAV`에 저장하고 끝냅니다.

## 실행

```
C:\> HANEDITL [파일이름]
```

DOSBox(메모리 1MB, 확장 메모리 없이 시험), FreeDOS, MS-DOS 5/6.x에서 실행됩니다.
DOSBox 1MB 설정에서 DOS의 빈 기본 메모리는 632KB이고, 그중 프로그램이 약 150KB를 쓰고
나머지가 문서·글꼴 캐시·되돌리기 기록에 쓰입니다. 실제 PC에서 드라이버가 많아 빈 메모리가
적으면 불러올 수 있는 문서 크기도 그만큼 줄어듭니다 (`MEM`으로 확인).

필요한 파일 (같은 디렉터리에 둠):

| 파일 | 크기 | 필요 여부 |
|---|---|---|
| `HANEDITL.EXE` | 약 130KB | 꼭 필요 |
| `HANEDIT.FNT` | 약 1.3MB | 꼭 필요 (글꼴). 없으면 실행하지 않고 알려 줌 |
| `HANJA.DIC` | 약 3.9MB | 한자 바꾸기(F9)를 쓸 때만 필요. 1.0의 것과 같은 파일 |
| `HANEDIT.CFG` | 1KB 미만 | 설정을 바꾸면 저절로 만들어짐. 1.0과 같은 형식 |

글꼴과 한자 사전을 디스크에서 읽으므로, 플로피보다는 하드 디스크(또는 램 디스크)에서
쓰는 것이 좋습니다. 디스크 캐시(SMARTDRV)가 있으면 더 빠릅니다.

## 글쇠

글쇠는 아래아 한글(한컴오피스 한글)의 단축키에 맞추었습니다.

| 글쇠 | 하는 일 |
|---|---|
| F10, 왼쪽 Alt (혼자 눌렀다 뗌), Esc | 메뉴 |
| Alt+F / E / Q / D / J / H | 파일 / 편집 / 찾기 / 입력 / 글꼴 / 도움말 메뉴를 바로 엶 |
| F1 | 도움말 |
| Alt-N | 새 문서 |
| Alt-O | 불러오기 (파일 목록 대화 상자, 디렉터리 이동 가능) |
| Alt-S, Ctrl-S | 저장하기 |
| Alt-V | 다른 이름으로 저장 |
| Alt-X | 끝내기 (고친 내용이 있으면 저장할지 물음) |
| Shift-Space, 오른쪽 Alt (한/영 키) | 한글/영문 전환 (둘 다 됨) |
| F9 또는 한자 키 (오른쪽 Ctrl) | 한자 바꾸기: 낱말 또는 한 글자 (아래 설명) |
| 화살표, Home, End, PgUp, PgDn | 커서 이동 |
| Ctrl-Home / Ctrl-End | 문서 처음 / 끝 |
| Ctrl-← / Ctrl-→ | 낱말 단위 이동 |
| Ins | 삽입 / 수정 상태 전환 |
| BackSpace, Del | 지우기 (조합 중에는 자모 단위로 지움, 블록이 있으면 블록을 지움) |
| F3 | 블록 설정: 한 번 누른 뒤 이동 글쇠로 범위를 정함. 두 번 = 낱말, 세 번 = 줄, 네 번 = 문서 전체 |
| Ctrl-A | 모두 선택 (문서 전체를 블록으로. 편집 메뉴에도 있음) |
| Shift + 화살표·Home·End·PgUp·PgDn | 블록 잡기 (Ctrl-Shift-←/→: 낱말 단위, Ctrl-Shift-Home/End: 문서 처음/끝까지) |
| Esc (블록이 있을 때) | 블록 풀기 |
| Ctrl-C 또는 Ctrl-Insert | 블록 복사하기 |
| Ctrl-X 또는 Shift-Delete | 블록 오려두기 (복사하고 지움) |
| Ctrl-V 또는 Shift-Insert | 붙이기 (블록이 있으면 블록 자리에) |
| Ctrl-Z | 되돌리기 |
| Ctrl-Shift-Z 또는 Ctrl-Y | 다시 실행 (되돌린 것을 다시) |
| F2, Ctrl-F, Ctrl-Q F | 찾기 (한글 입력 가능) |
| Ctrl-L | 다시 찾기 |
| Alt-G | 줄 찾아가기 (줄 번호로 이동) |
| Alt-B | 배경색 변경: 편집 영역의 글자색과 바탕색을 맞바꿈 (파일 메뉴에도 있음) |

메뉴 이름 옆 괄호 안의 글자는 Alt와 함께 누르는 글자입니다. 아래아 한글은 Alt+글자를
명령(Alt-S 저장, Alt-G 찾아가기, Alt-I 상용구 …)에 쓰므로, 메뉴 글자는 이와 겹치지 않게
찾기(Q)·입력(D)·글꼴(J)로 정했습니다. 입력(D)은 한컴오피스 한글의 '입력(D)'과 같습니다.
메뉴가 열린 상태에서는 Alt 없이 글자만 눌러도 그 메뉴로 옮겨 갑니다.

입력 메뉴에서 두벌식 / 세벌식 최종 자판을 고를 수 있습니다. 한글/영문 전환은 아래 두 글쇠
모두 언제든 쓸 수 있습니다.

- **Shift-Space**: 왼쪽·오른쪽 Shift 모두 가능
- **오른쪽 Alt (한/영 키)**: 눌렀다 뗄 때 전환 (다른 글쇠와 함께 누르면 전환 안 함).
  한/영 키가 F2 코드를 보내는 한국어 자판도 인식. 메뉴는 왼쪽 Alt를 혼자 눌렀다 떼면 열림

## 한자 바꾸기

한글을 친 뒤 **F9** 또는 **한자 키**(오른쪽 Ctrl만 눌렀다 뗌. 한자 키가 F1 코드를 보내는
한국어 자판도 인식)를 누르면 후보 상자가 뜹니다. 두 글쇠는 언제나 함께 쓸 수 있습니다.

- **블록이 없을 때**: 커서 바로 앞에 이어진 한글 중 사전에 있는 **가장 긴 낱말**을 찾아
  바꿉니다 (예: "우리 대한민국|" → 대한민국 → 大韓民國). 낱말이 없으면 커서 앞(없으면
  커서 자리)의 **한 글자**를 바꿉니다. 조합 중인 글자도 포함됩니다
- **블록이 있을 때**: 한 줄 안의 한글 블록(12자까지)을 그대로 낱말로 바꿉니다.
  "한국은"처럼 뒤에 조사가 붙었거나 한 글자만 바꾸고 싶을 때는 바꿀 부분만 블록으로
  잡으십시오
- 후보 상자: 번호·한자·뜻. 낱말은 글자마다 첫째 뜻을 이어 보여 줌
  (예: "士氣 선비 사·기운 기", "詐欺 속일 사·속일 기"). 한 쪽에 9개, 자주 쓰는 순서
- 고르기: 숫자 1~9, 또는 ↑↓ 후 Enter / 쪽 넘기기: PgDn·PgUp (→ ← Space) / 취소: Esc
- 바꾼 것은 Ctrl-Z로 되돌릴 수 있습니다

사전 `HANJA.DIC`(약 3.9MB)은 `HANEDITL.EXE`와 같은 디렉터리에 두어야 합니다. libhangul의
한자 사전으로 만든 것으로 두 부분으로 되어 있습니다.

- 한 글자: 한글 527음절, 한자 후보 21,824개 (약 240KB). lite는 음절 색인(약 4KB)만 메모리에 두고 후보와 뜻은 그때그때 파일에서 읽음
- 낱말: 186,679개, 후보 238,031개. 메모리에 읽지 않고 파일에서 바로 찾음 (이진 탐색,
  한 번 찾는 데 약 20번 읽기). 후보는 libhangul의 낱말 빈도 자료(freq-hanjaeo.txt) 순

글꼴에 없는 드문 한자(CJK 확장 A 영역)가 든 항목은 넣지 않았습니다. 다시 만들려면:

```sh
python3 tools/genhanja.py libhangul/data/hanja/hanja.txt libhangul/data/hanja/freq-hanjaeo.txt HANJA.DIC
```

글꼴 메뉴에서 본문의 한글을 넓은 한글 / 좁은 한글 중에서 고를 수 있습니다. 메뉴와
대화 상자는 늘 넓은 한글입니다. 화면에 보이는 폭만 바뀌고 문서 내용은 그대로입니다.

## 자동 줄 바꿈

글꼴 메뉴의 **자동 줄 바꿈**(√)을 켜면, 화면 오른쪽 끝(80칸)을 넘는 줄이 가로로 스크롤되지
않고 다음 화면 줄로 이어져 보입니다. 메모장의 '자동 줄 바꿈'이나 아래아 한글의 문단처럼
**화면에서만** 나누어 보여 줄 뿐, 파일에는 줄바꿈이 들어가지 않습니다.

- 띄어쓰기 자리에서 나눕니다. 띄어쓰기 없이 한 줄보다 긴 낱말은 글자 단위로 나눕니다
- ↑↓·PgUp·PgDn은 화면 줄 단위로, Home·End는 그 화면 줄의 처음·끝으로 옮깁니다
  (Ctrl-Home·Ctrl-End는 문서 처음·끝). 눈금자의 ▼는 화면 줄 안의 칸을 가리킵니다
- 상태 줄의 '줄 n'은 파일의 줄 번호, '칸 n'은 그 줄 처음부터 센 칸입니다
- 처음에는 꺼져 있고, 바꾸면 설정 파일에 저장됩니다

## 설정 파일 (HANEDIT.CFG)

본문 글꼴, 배경색, 자동 줄 바꿈은 `HANEDITL.EXE`와 같은 디렉터리의 `HANEDIT.CFG`에
저장됩니다. 메뉴나 Alt-B로 바꾸는 즉시 저장되고, 다음에 켤 때 그대로 불러옵니다. 파일이
없으면 넓은 한글·어두운 바탕으로 시작합니다. 손으로 고쳐도 됩니다
(대소문자·앞뒤 공백 무시, `;` 뒤는 주석):

```
font=wide        ; wide (넓은 한글) | narrow (좁은 한글)
colors=dark      ; dark (어두운 바탕) | light (밝은 바탕)
wrap=off         ; off | on (자동 줄 바꿈)
```

예전 판이 저장한 `hankey=` 줄은 무시하고, 다음에 설정을 저장할 때 빠집니다.

EXE가 쓰기 금지된 곳(예: 읽기 전용 디스크)에 있으면 설정을 저장하지 못했다는 알림이
나오고, 설정은 그 실행 동안만 유지됩니다.

블록은 파란 바탕으로 표시되고, 상태 줄에 블록 글자 수가 나옵니다. 블록을 잡은 채
글자·Enter·Tab을 치면 블록이 지워지고 그 자리에 입력됩니다. 숫자판 방향키도
Shift와 함께 쓰면 블록을 잡습니다.

복사한 내용은 프로그램 안에서만 쓰이며(여러 줄 가능) 프로그램을 끝내면 사라집니다.
붙이기는 수정 상태에서도 늘 끼워 넣기로 동작합니다. 편집 메뉴에서도 쓸 수 있습니다.

되돌리기(Ctrl-Z)는 최근 1,000번의 편집까지 거슬러 올라갈 수 있습니다. 이어서 친 글자는
낱말 단위로, 이어서 누른 BackSpace·Del은 한 묶음으로 되돌려집니다. 줄바꿈, 블록 지우기,
붙이기, 오려두기는 각각 한 번에 되돌려집니다. 저장한 상태까지 되돌리면
제목 줄 파일 이름 옆의 '*'(수정됨 표시)가 사라집니다. 새 문서를 열거나 파일을 불러오면 기록이 지워집니다.

다시 실행(Ctrl-Y)은 되돌린 편집을 같은 단위로 다시 적용합니다. 되돌린 뒤 새로 글을
고치면 그때부터 다시 실행할 기록은 사라집니다.

## 빌드 (Open Watcom 2.0)

```sh
export WATCOM=/opt/watcom PATH=$WATCOM/binl64:$PATH INCLUDE=$WATCOM/h
wmake            # -> HANEDITL.EXE (wcc -ml large 모델, -zt=256, 스택 16KB)
```

글꼴 파일 `HANEDIT.FNT`를 다시 만들려면 (1.0의 내장 글꼴과 같은 내용):

```sh
# 갈무리 BDF는 npm 패키지 galmuri의 dist/ 폴더에 있음
python3 tools/genfont.py unifont.hex Galmuri14.bdf GalmuriMono11.bdf Galmuri11-Condensed.bdf --fnt HANEDIT.FNT
```

`HANEDIT.FNT` 형식: `"HFN1"`, u16 본 표 범위 수, u16 넓은 한글 표 범위 수,
범위마다 {u16 첫 글자, u16 끝 글자, u8 넓음, u8 0, u32 파일 안 위치}, 그 뒤에 글자 그림
(8×16은 16바이트, 16×16은 32바이트). 범위 표만 메모리에 읽어 두면 글자 폭은 디스크를 읽지 않고 알 수 있습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `src/main.c` | 편집기 본체 (1.0과 같음 + 16비트 한도 검사, 나눠 읽기, 비상 저장, 한자 사전 디스크 읽기) |
| `src/vga.c` | 모드 12h 그리기 (VGA 메모리를 `MK_FP(0xA000,0)` far 포인터로) |
| `src/kbd.c` | 글쇠 처리 (1.0과 같음, `int86`과 BIOS 데이터 영역 far 포인터) |
| `src/fontfile.c` | `HANEDIT.FNT` 범위 표 + 2방향 집합 연관 글자 캐시 (512집합 × 2) |
| `libhangul/` | libhangul 입력 오토마타 (원본 그대로) |
| `tools/genfont.py` | 글꼴 변환 (`--fnt`로 HANEDIT.FNT), `tools/genhanja.py`: 한자 사전 |

## 제한

- 위의 문서 크기 한도 (8,000줄, 한 줄 30,000자, 메모리)
- 탭은 불러올 때 8칸 간격 공백으로 바뀝니다
- BMP 밖 문자(이모지 등)와 잘못된 UTF-8 바이트는 U+FFFD로 바뀝니다
- 한자 → 한글 되바꾸기는 없습니다 (Ctrl-Z로 되돌리기는 됨)

  가득 한글일 때 약 250ms → 약 19ms). 메뉴 줄·제목 줄·눈금자와 커서가 없는 본문 줄은 바뀌지
  않았으면 지난번에 만든 줄을 그대로 쓰고(줄마다 고친 번호로 판단), 빈칸 채우기와 영문·한글 폭
  계산에 빠른 길을 둠. 화면 기억에 메모리 약 19KB를 더 씀. 화면 모양은 1.0과 같음
- **1.0** — 첫 판 (당시 이름 HANEDIT mini. HANEDIT 1.0.1 기능을 16비트 리얼 모드로)
